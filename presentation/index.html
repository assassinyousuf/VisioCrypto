01 / MOTIVATION & PROBLEM

Why Commercial Cloud Backups Leak Privacy

⚠️ The Conflict in Mobile Cloud Storage

  • Cloud Provider Compromises: Outsourcing photos and documents to Google Drive, Dropbox, or S3 exposes data to data breaches and insider harvesting.
  • The Search Dilemma: Traditional client-side encryption renders files into opaque blobs, breaking keyword search.
  • Client Resource Limits: Downloading and decrypting the entire database locally for every search drains phone battery and network quota.
  • The Volume Leakage Threat: Standard Searchable Symmetric Encryption (SSE) reveals how many files match each query. Statistical adversaries exploit this volume pattern to reconstruct private search queries.

03 / CRYPTOGRAPHIC ENGINE

Domain-Separated Cryptographic Construction

🔑 4-Way HKDF-SHA256 Key Derivation

Derived from hardware-backed master secret K:

  • $K_{\text{enc}}$ (File Stream Encryption): AES-CTR-256 with HMAC integrity.
  • $K_{\text{search}}$ (Search Trapdoors): $T_w \leftarrow \text{HMAC-SHA256}(w)$.
  • $K_{\text{index}}$ (Payload Encryption): AES-GCM-256 authenticated index blocks.
  • $K_{\text{update}}$ (Versioned Dynamic PRF): Unlinkable dynamic additions.

🛡️ Formal Security Guarantees

  • $\mathcal{L}_{\text{dyn-VH}}\text{-IND-CKA2}$ Security: Proven adaptively secure against chosen-keyword attacks via game hopping.
  • Forward Privacy: Versioned state tokens ($V[w]$) ensure past searches cannot be linked to newly uploaded files.
  • Type-II Backward Privacy: Deleted documents are immediately removed from search results without revealing cancellation pairings to the server.
04 / PRIVACY & MEMORY HYGIENE

Local Bloom Filter & Mobile Heap Protection

🌸 Local Bloom Filter Deletions

  • Sub-Millisecond Execution: Dynamic deletions are inserted into an in-memory Bloom filter ($117\text{ KB}$, $P_e \le 10^{-4}$).
  • Zero Network Roundtrips: Handset filters deleted document IDs locally during query decryption in $< 0.08\text{ ms}$ without contacting the cloud.
  • Eliminates ORAM: Bypasses heavy multi-round oblivious RAM reconstruction.
